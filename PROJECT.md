# EntomoIQ (EIQ)

California Branch II structural pest identification and field guide.

## Project principles
- Preserve all approved pest posters and original guide versions.
- California Branch II scope only; no termite treatment guidance (Branch III).
- Visual-first identification; uncertain matches must be labeled tentative.
- Maintain forest-green/cream field-guide poster style and fullscreen poster viewing.
- Verify product directions against current product labels and California DPR registration status.
- Do not treat GitHub project scaffolding as a verified guide import.

## Source versions
The original HTML guides are preserved in the ChatGPT file Library. V24.97 is an approved integrated poster baseline; a newer V24.98 German cockroach update also exists and must be reviewed before choosing the working baseline.
