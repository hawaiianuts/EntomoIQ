# EntomoIQ — California Branch II Product Verification Register
Updated: 2026-11-02

## Status and safety rules
This is an inventory and verification worklist, NOT an authorization to apply a pesticide. Existing inventory names are carried forward as user-confirmed; no current label, SDS, California DPR registration, or permitted-use status is independently verified by this file.

Before displaying a product as field-verified, confirm the exact product formulation, EPA registration number, current manufacturer label, SDS, California DPR product registration/status, site and pest directions, application rates, PPE, restrictions, and any local or employer requirements. Never infer that an inactive registration number means the product itself is discontinued. Record a source URL and verification date for every check.

Scope: California Branch II structural pest control. No Branch I fumigation, Branch III termite work, landscape/turf uses, or unapproved treatment sites. Follow the actual label.

## Required product record fields
- Product display name and exact formulation
- Manufacturer, EPA registration number, California registration identifier/status
- Current label URL, SDS URL, dates checked and document revisions
- Active ingredient(s), formulation category, PPE, signal word
- Permitted structural treatment sites and pest targets explicitly on label
- Restrictions, seasonal/employer limitations, and special precautions
- Truck inventory yes/no and last confirmation
- Verification state: pending / verified / needs review
- Source citations and reviewer notes
